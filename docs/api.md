# 域名解析图 API 文档

## 基本信息

### 获取域名解析图URL

**接口描述**：获取指定域名的解析图URL

- **请求方法**：GET
- **请求路径**：`/api/domain-graph-url`
- **请求参数**：
  - `domain`：要查询的域名（必填，字符串类型）

**请求示例**：
```
GET http://127.0.0.1:50005/api/domain-graph-url?domain=baidu.com
```

**返回格式**：JSON

**成功响应示例**：
```json
{
    "success": true,
    "domain": "baidu.com",
    "url": "http://127.0.0.1:50005/domain-graph/baidu.com",
    "message": "点击URL查看域名解析图"
}
```

**错误响应示例**：
```json
{
    "error": "缺少域名参数"
}
```

## 使用说明

1. 启动服务
   ```bash
   python app.py
   ```

2. 访问Web界面
   - 打开浏览器访问：`http://127.0.0.1:50005`
   - 在输入框中输入要查询的域名
   - 点击submit按钮提交查询

3. 查看解析结果
   - 页面将显示域名的解析图
   - 双击节点可查看详细信息

## 错误码说明

| 状态码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 400 | 请求参数错误，如缺少域名参数 |
| 500 | 服务器内部错误 |

## 注意事项

1. 域名参数必须是有效的域名格式
2. 建议使用现代浏览器（Chrome、Firefox等）访问，以获得最佳展示效果
3. 解析大型域名时可能需要等待较长时间，请耐心等待
